THIS FILE IS GUIDANCE, NOT TEXT TO PASTE.

OEIS policy ("Use of AI for OEIS Submissions", https://oeis.org/wiki/Use_of_AI_for_OEIS_Submissions, page last
edited 29 August 2026) lists as NOT permitted:
  - "Using AI to generate the full text of comments."
  - "Pasting AI-generated text into the Pink Boxes as responses to editorial queries."
  - "Claiming an AI-tool or other program as an author or co-author."
  - "Submitting any AI-generated program that you do not understand how it works or its operational limits."
  - "Bulk or serial submissions of sequences generated by AI or any other automated, mechanical, or programmatic
    process (unless prior permission is given)."
The same page says that every contribution must have a human author, that the author is responsible for the
correctness of anything produced with an AI tool, and that these conditions apply to updates of existing
sequences as well as to new ones.  It states no requirement to disclose AI assistance.  A non-compliant update
"may be rejected even if it has mathematical merit".

Consequences for this contribution: the comment has to be written by you, in your own words; you must be able to
explain the checking program if you include it; replies to editors must be your own.  This package was prepared by
an AI assistant, so it gives you verified facts, data and conventions -- not wording.

1. What the contribution consists of

   (a) one new comment in the COMMENTS section of A062714;
   (b) one new line in the LINKS section;
   (c) one supporting file, a062714.txt (in this directory), uploaded from the edit page of A062714.
   No terms are added.  a(10) and all later terms remain unknown, and the keyword "more" stays.

2. Facts for the comment (compose the sentence yourself)

   - a(11) <= 101, a(12) <= 121, a(13) <= 144, a(14) <= 169, a(15) <= 196.
   - The first comment of the entry already states Radomirovic's bound ceiling(n^2 - (7/3)*n + 19/3) for n >= 7.
     For n = 11..15 it gives 102, 123, 145, 170, 197.  Refer to that comment rather than repeating the formula.
   - Sequences of the five lengths are in the supporting file; the usual OEIS way to point to it is
     "see the <your surname> link".
   - Optional consequence.  That bound is <= (n-1)^2 exactly when n >= 16, and the new sequences for
     n = 12, 13, 14, 15 have lengths 11^2, 12^2, 13^2, 14^2; hence a(n) <= (n-1)^2 for all n >= 12.
     This does NOT include n = 11, where the new length is 101 = 10^2 + 1.
   - These are upper bounds only; do not describe them as optimal or as terms.

3. Conventions (OEIS Style Sheet, https://oeis.org/wiki/Style_Sheet)

   - For this contribution, put the upper bounds in COMMENTS. Do not append them to DATA as exact terms.
   - Plain ASCII notation: <= and >=, ceiling(...), n^2, (n-1)^2.
   - End the comment with " - ~~~~" (space, dash, space, four tildes).  The system replaces the tildes by your
     user name and the date.
   - People who are not OEIS users are written as plain names, as in the existing "Radomirovic (2012)".
   - A LINKS line is not signed, begins with your name in plain text, and goes in alphabetical order by surname
     among the existing links.  Its form is
         First Last, <a href="/A062714/a062714.txt">a short title that you write</a>

4. The supporting file

5. Before you submit

   - Run "sh run_all.sh" yourself and read sections 3 and 4 of NOTE.md, so that you can vouch for the five bounds.
   - Provenance.  The OEIS rules quoted above neither require nor forbid mentioning AI assistance, and they do not
     allow an AI tool to be named as an author.  Suggestion from the assistant that prepared this package: state
     in the supporting file, in a sentence of your own, that the sequences were found by a computer search carried
     out with an AI assistant and that you checked them yourself.
   - Editors may ask questions in the pink boxes.  Answer them in your own words.
   - Priority is not established by this package (NOTE.md, sections 1 and 6).  If an editor or reader points to an
     earlier source for any of these bounds, the comment should credit it.
