PROVENANCE of the witnesses (search runs; not needed for verification)

Each witness is the sequence found by the search (symbols 0..n-1) with the symbols renamed 1..n in order of
first appearance.  Sources and logs are in search/:
  search/sa.c        first annealer (recomputes the count of missing permutations after every move)
  search/sa2.c       second annealer (heat-bath sweeps using the split evaluation); built twice:
                       sa2_32:  cc -O3 -DCT=uint32_t -o sa2_32 sa2.c -lm
                       sa2_64:  cc -O3 -o sa2_64 sa2.c -lm
  search/gen_t2.py   prints x s1 x ... x sn x for the list T2(n) of Tan 2022 (start sequence for n = 13)
  search/logs/       standard output (.out; lines 'FOUND n=.. L=.. : sequence') and standard error (.err)
                     of the runs named below
Arguments of sa2: n, target length, seed, time limit in seconds, start file, T0, T1, sweeps per cycle.
A start file '-' means the built-in construction of length (n-1)^2+3 (Schoenfield, OEIS A062714 comments).
Arguments of sa: n, target length, seed, time limit in seconds; it always starts from that construction.
The binaries used were built with 'clang -O3 -march=native' on an Apple M2.
